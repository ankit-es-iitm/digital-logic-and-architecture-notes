# Digital Logic & Computer Architecture Notes

Repository to organize my practice files, truth tables, and summary notes from my Electronic Systems coursework.

### Topics Covered:
* **Digital Logic Design:** Combinational & sequential circuits (Multiplexers, Flip-Flops, Counters, FSMs).
* **Verilog HDL Basics:** Gate-level and behavioral modeling for basic logic blocks.
* **Computer Architecture:** 
  * x86 and RISC-V instruction set basics.
  * 5-stage instruction pipelining (Fetch, Decode, Execute, Memory, Writeback).
  * Pipeline hazards (Data, Structural, and Control hazards) and memory segmentation.

*(Updating with lab practice files and circuit diagrams regularly)*
